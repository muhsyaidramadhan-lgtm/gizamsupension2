# Gizam Suspension Kendari

Website toko shockbreaker Gizam Suspension Kendari.

## Local

```bash
npm install
npm run dev
```

## Deploy GitHub Pages

1. Pastikan `vite.config.ts` punya:
   ```ts
   base: '/gizamsupension2/',
   ```
2. Repo → **Settings** → **Pages** → Source: **GitHub Actions**
3. Push ke branch `main`
4. Tunggu tab **Actions** selesai (hijau)
5. Buka: https://muhsyairamadhan-lgtm.github.io/gizamsupension2/
